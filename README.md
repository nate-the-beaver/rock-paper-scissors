# rock-paper-scissors
A simple "Rock, Paper Scissors" game made in Python using the PyQt5 module. 
Requires PyQt5 to run.

From the main page, a user is welcomed to the game and moved on to the choice page. Here, not only is the score displayed, but the user is directed to decide whether to choose rock, paper, or scissors. From there, they are guided to a reveal page, where the fate of the match is displayed, in addition to the player and computer choice. After, a user can choose to play again, bringing them back to the choice page, but with an updated scoreboard.
